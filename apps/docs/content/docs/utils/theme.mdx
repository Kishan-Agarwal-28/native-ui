## Overview

All NativeUI components consume a central `THEME` object and `useTheme` hook from `@/lib/theme`. The theme defines four token categories:

| Category | Description |
|----------|-------------|
| `colors` | Semantic color palette (background, foreground, primary, muted, …) |
| `spacing` | Consistent spacing scale from `xs` (4) to `3xl` (32) |
| `radius` | Border-radius scale from `sm` (4) to `full` (9999) |
| `typography` | Font-size scale from `xs` (11) to `2xl` (24) |

The theme provider is enhanced with **animated theme transitions** (using Skia and Reanimated) and **optional persistence** (using `react-native-mmkv`).

## Setup

Wrap your root layout with `ThemeProvider`. You can optionally enable theme persistence with the `persist` prop:

```tsx title="app/_layout.tsx"
import { ThemeProvider } from '@/lib/theme';

export default function RootLayout({ children }) {
  return (
    <ThemeProvider persist={true}>
      {children}
    </ThemeProvider>
  );
}
```

## Usage in components

```tsx
import { THEME, useTheme } from '@/lib/theme';
import { View, Text } from 'react-native';

function MyComponent() {
  const { theme } = useTheme();
  const { colors, spacing, radius, typography } = THEME[theme];

  return (
    <View style={{
      backgroundColor: colors.card,
      padding: spacing.lg,
      borderRadius: radius.lg,
    }}>
      <Text style={{ fontSize: typography.base, color: colors.foreground }}>
        Hello!
      </Text>
    </View>
  );
}
```

## Changing the theme

We recommend using the dedicated `theme-toggle` component to smoothly transition between themes. If you prefer to implement your own toggle, you can use `triggerTransition`:

```tsx
import { useThemeTransition } from '@/lib/theme';
import { TouchableOpacity } from 'react-native';

function CustomThemeToggle() {
  const { triggerTransition } = useThemeTransition();

  return (
    <TouchableOpacity onPress={(e) => {
      triggerTransition({
        x: e.nativeEvent.pageX,
        y: e.nativeEvent.pageY,
        type: 'circular'
      });
    }}>
      <Text>Toggle Theme</Text>
    </TouchableOpacity>
  );
}
```

## API Reference

### THEME

```ts
const THEME: Record<"light" | "dark" | "unspecified", ThemeConfig>
```

A static object containing the full theme config for each color scheme. Access it as `THEME[theme]` where `theme` is the current value from `useTheme()`.

### ThemeProvider

```tsx
<ThemeProvider persist={boolean}>
  {children}
</ThemeProvider>
```

Provides `theme` and `setTheme` via context, enables Skia transitions, and can automatically persist the theme choice with `react-native-mmkv` if `persist={true}` is set.

### useTheme

```ts
const { theme, setTheme } = useTheme();
```

| Return value | Type | Description |
|--------------|------|-------------|
| `theme` | `"light" \| "dark" \| "unspecified"` | Current active theme. |
| `setTheme` | `(theme: Theme) => void` | Update the active theme. |

### useThemeTransition

```ts
const { triggerTransition } = useThemeTransition();
```

Use `triggerTransition` to smoothly animate the theme change. You must pass the coordinates `x` and `y` where the transition should originate.
